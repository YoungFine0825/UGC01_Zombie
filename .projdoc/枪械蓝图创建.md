### 枪械蓝图创建规范 (AI Agent Rule)

本文档定义了创建枪械蓝图资产的完整流程，供 AI Agent 自动化执行。

> **枪械模板/弹药模板速查表** → [枪械蓝图参考表.md](枪械蓝图参考表.md)

## 资产命名规范

| 资产类型 | 命名格式 | 示例 |
|---------|---------|------|
| 1级枪械蓝图 | `BP_Weapon_{枪械类型}_{枪械名称}` | `BP_Weapon_SMG_Uzi` |
| 2级枪械蓝图 | `BP_Weapon_{枪械类型}_{枪械名称}_Lv2` | `BP_Weapon_SMG_Uzi_Lv2` |
| 1级枪械物品蓝图 | `BP_Inventory_{枪械类型}_{枪械名称}` | `BP_Inventory_SMG_Uzi` |
| 2级枪械物品蓝图 | `BP_Inventory_{枪械类型}_{枪械名称}_Lv2` | `BP_Inventory_SMG_Uzi_Lv2` |
| 弹药物品蓝图 | `BP_Inventory_Bullet_{枪械名称}` | `BP_Inventory_Bullet_Uzi` |

枪械类型枚举：`Pistol`(手枪)、`SMG`(冲锋枪)、`Rifle`(突击步枪)、`Sniper`(狙击枪)、`ShotGun`(霰弹枪)、`MachineGun`(机枪)

## 创建流程 (严格按顺序执行)

### 核心原则

1. **逐把枪械执行**：每把枪械独立执行完整流程，上一把完成后才开始下一把
2. **物品蓝图逐个创建**：每个物品蓝图创建后需等待编辑器分配 ItemID，确认后再创建下一个
3. **先枪械后物品**：先创建枪械蓝图（Step 1-3），再创建物品蓝图（Step 4-8）
4. **两阶段分离**：蓝图创建（阶段一）和配置表操作（阶段二）分开执行

### 单把枪械创建流程

对每把枪械，按以下顺序执行：

#### Step 1: 创建1级枪械蓝图

从内置枪械模板创建，**使用 `objed_create_asset`**。

```python
path_w1 = ue.objed_create_asset('Item', '枪械', '{模板名称}', 'BP_Weapon_{类型}_{名称}')
# 例: ue.objed_create_asset('Item', '枪械', 'UZI', 'BP_Weapon_SMG_Uzi')
```

#### Step 2: 给1级枪械蓝图添加 WeaponSystemComponent

**使用 `add_component_to_blueprint`**，组件类名为 `BP_WeaponSystemComponent_C`。

```python
from unreal_engine.classes import Blueprint

bp_w1 = ue.load_object(Blueprint, '{Step1返回的路径}')
comp_class = ue.find_class('BP_WeaponSystemComponent_C')
ue.add_component_to_blueprint(bp_w1, comp_class, 'WeaponSystemComponent')
ue.compile_blueprint(bp_w1)
bp_w1.save_package()
```

#### Step 3: 创建2级枪械蓝图

**以1级枪械蓝图为父类创建子蓝图，使用 `create_blueprint`**。

⚠️ 禁止使用 `objed_duplicate_asset`，它只复制资产不改变父类。

```python
bp_w1 = ue.load_object(Blueprint, '{Step1返回的路径}')
root = ue.get_project_root()
bp_lv2 = ue.create_blueprint(
    bp_w1.GeneratedClass,  # 父类 = 1级枪械蓝图的 GeneratedClass
    root + '/Asset/Blueprint/Prefabs/Weapons/BP_Weapon_{类型}_{名称}_Lv2'
)
ue.compile_blueprint(bp_lv2)
bp_lv2.save_package()
```

#### Step 4: 创建1级枪械物品蓝图 + 确认 ItemID

从内置枪械物品模板创建，**使用 `objed_create_asset`**。

⚠️ 创建后需延迟等待编辑器分配 ItemID。

```python
import time

path_i1 = ue.objed_create_asset('Item', '物品', '{物品模板名称}', 'BP_Inventory_{类型}_{名称}')
# 例: ue.objed_create_asset('Item', '物品', 'UZI 冲锋枪模板', 'BP_Inventory_SMG_Uzi')

# 设置 WeaponClass
bp_i1 = ue.load_object(Blueprint, path_i1)
bp_w1 = ue.load_object(Blueprint, '{Step1返回的路径}')
bp_i1.GeneratedClass.get_cdo().WeaponClass = bp_w1.GeneratedClass
bp_i1.save_package()

# 延迟等待编辑器分配 ItemID
time.sleep(2)

# 确认 ItemID
bp_i1 = ue.load_object(Blueprint, path_i1)
item_id_lv1 = bp_i1.GeneratedClass.get_cdo().ItemID
ue.log("Lv1 ItemID: " + str(item_id_lv1))  # 应为7位数，如 8310029
```

#### Step 5: 创建2级枪械物品蓝图 + 确认 ItemID

**以1级枪械物品蓝图为父类创建子蓝图，使用 `create_blueprint`**。

⚠️ 禁止使用 `objed_duplicate_asset`。创建后需延迟等待 ItemID。

```python
bp_i1 = ue.load_object(Blueprint, '{Step4返回的路径}')
root = ue.get_project_root()
bp_i_lv2 = ue.create_blueprint(
    bp_i1.GeneratedClass,  # 父类 = 1级物品蓝图的 GeneratedClass
    root + '/Asset/Blueprint/Prefabs/Items/BP_Inventory_{类型}_{名称}_Lv2'
)
ue.compile_blueprint(bp_i_lv2)
bp_i_lv2.save_package()

# 设置 WeaponClass
bp_i_lv2 = ue.load_object(Blueprint, '{Step5创建的路径}')
bp_w2 = ue.load_object(Blueprint, '{Step3创建的路径}')
bp_i_lv2.GeneratedClass.get_cdo().WeaponClass = bp_w2.GeneratedClass
bp_i_lv2.save_package()

# 延迟等待 ItemID
time.sleep(2)

# 确认 ItemID
bp_i_lv2 = ue.load_object(Blueprint, '{Step5创建的路径}')
item_id_lv2 = bp_i_lv2.GeneratedClass.get_cdo().ItemID
ue.log("Lv2 ItemID: " + str(item_id_lv2))
```

#### Step 6: 创建弹药物品蓝图 + 确认 ItemID

从弹药模板创建，**使用 `objed_create_asset`**。弹药物品蓝图只有一个，不区分1级2级。

```python
path_b = ue.objed_create_asset('Item', '物品', '{弹药模板名称}', 'BP_Inventory_Bullet_{名称}')
# 例: ue.objed_create_asset('Item', '物品', '9毫米子弹模板', 'BP_Inventory_Bullet_Uzi')

# 延迟等待 ItemID
time.sleep(2)

# 确认 ItemID
bp_b = ue.load_object(Blueprint, path_b)
item_id_bullet = bp_b.GeneratedClass.get_cdo().ItemID
ue.log("Bullet ItemID: " + str(item_id_bullet))
```

## 批量创建多把枪械的流程

当需要创建多把枪械时，按以下流程执行：

```python
import time
from unreal_engine.classes import Blueprint
import unreal_engine as ue

root = ue.get_project_root()
comp_class = ue.find_class('BP_WeaponSystemComponent_C')

# 枪械列表
weapons = [
    {'name': 'UMP45', 'type': 'SMG', 'template': 'UMP45', 'item_template': 'UMP45 冲锋枪模板', 'ammo_template': '.45口径子弹模板'},
    {'name': 'Vector', 'type': 'SMG', 'template': 'Vector', 'item_template': 'Vector 冲锋枪模板', 'ammo_template': '9毫米子弹模板'},
    # ... 更多枪械
]

for w in weapons:
    name = w['name']
    wtype = w['type']
    
    ue.log("===== " + name + " =====")
    
    # Step 1-3: 创建枪械蓝图（可以快速执行）
    path_w1 = ue.objed_create_asset('Item', '枪械', w['template'], 'BP_Weapon_' + wtype + '_' + name)
    bp_w1 = ue.load_object(Blueprint, path_w1)
    ue.add_component_to_blueprint(bp_w1, comp_class, 'WeaponSystemComponent')
    ue.compile_blueprint(bp_w1)
    bp_w1.save_package()
    
    bp_w1 = ue.load_object(Blueprint, path_w1)
    bp_lv2 = ue.create_blueprint(bp_w1.GeneratedClass, root + '/Asset/Blueprint/Prefabs/Weapons/BP_Weapon_' + wtype + '_' + name + '_Lv2')
    ue.compile_blueprint(bp_lv2)
    bp_lv2.save_package()
    
    # Step 4: 创建1级物品蓝图（逐个创建，等待 ItemID）
    path_i1 = ue.objed_create_asset('Item', '物品', w['item_template'], 'BP_Inventory_' + wtype + '_' + name)
    bp_i1 = ue.load_object(Blueprint, path_i1)
    bp_i1.GeneratedClass.get_cdo().WeaponClass = bp_w1.GeneratedClass
    bp_i1.save_package()
    time.sleep(2)  # 等待编辑器分配 ItemID
    item_id_lv1 = ue.load_object(Blueprint, path_i1).GeneratedClass.get_cdo().ItemID
    ue.log("Lv1 ItemID: " + str(item_id_lv1))
    
    # Step 5: 创建2级物品蓝图（逐个创建，等待 ItemID）
    bp_i1 = ue.load_object(Blueprint, path_i1)
    bp_i_lv2 = ue.create_blueprint(bp_i1.GeneratedClass, root + '/Asset/Blueprint/Prefabs/Items/BP_Inventory_' + wtype + '_' + name + '_Lv2')
    ue.compile_blueprint(bp_i_lv2)
    bp_i_lv2.save_package()
    bp_i_lv2 = ue.load_object(Blueprint, root + '/Asset/Blueprint/Prefabs/Items/BP_Inventory_' + wtype + '_' + name + '_Lv2')
    bp_i_lv2.GeneratedClass.get_cdo().WeaponClass = bp_lv2.GeneratedClass
    bp_i_lv2.save_package()
    time.sleep(2)  # 等待编辑器分配 ItemID
    item_id_lv2 = ue.load_object(Blueprint, root + '/Asset/Blueprint/Prefabs/Items/BP_Inventory_' + wtype + '_' + name + '_Lv2').GeneratedClass.get_cdo().ItemID
    ue.log("Lv2 ItemID: " + str(item_id_lv2))
    
    # Step 6: 创建弹药物品蓝图（逐个创建，等待 ItemID）
    path_b = ue.objed_create_asset('Item', '物品', w['ammo_template'], 'BP_Inventory_Bullet_' + name)
    time.sleep(2)  # 等待编辑器分配 ItemID
    item_id_bullet = ue.load_object(Blueprint, path_b).GeneratedClass.get_cdo().ItemID
    ue.log("Bullet ItemID: " + str(item_id_bullet))
    
    ue.log(name + " done: Lv1=" + str(item_id_lv1) + " Lv2=" + str(item_id_lv2) + " Bullet=" + str(item_id_bullet))
```

### Step 8: 添加 DT_WeaponConfigs 配置

DT_WeaponConfigs 存储枪械的弹药、槽位等运行时配置。

**表结构**（12个字段）：

| 字段 | 类型 | 说明 |
|------|------|------|
| Id | int | 配置ID，格式 100XY（X=组号，Y=等级） |
| WeaponItemId | int | 枪械物品ID（来自 UGCBattleItem） |
| AmmoItemId | int | 弹药物品ID（来自 UGCBattleItem） |
| DeliverAmmoNumber | int | 初始/拾取弹药数 |
| WeaponName | str | 武器显示名称 |
| WeaponDesc | str | 武器描述 |
| WeaponLevel | int | 等级（1=Lv1, 2=Lv2） |
| WeaponSlots | array | 武器槽位配置（Struct_WeaponSlotConfig） |
| WeaponClass | SoftClassPath | 武器蓝图路径（指向 BP_Weapon_ 前缀蓝图） |
| GrenadeClass | SoftClassPath | 投掷物蓝图路径 |
| MinWeaponNum | int | 最小持有数（通常为0） |
| MaxWeaponNum | int | 最大持有数（通常为1） |

**Id 递增规则**：

```
格式: 100XY
  X = 武器组号（01, 02, 03... 递增）
  Y = 等级（1=Lv1, 2=Lv2）

示例:
  10011/10012 = P92 Lv1/Lv2
  10021/10022 = MP5K Lv1/Lv2
  ...
  新武器: 查询当前最大组号，+1 后使用
```

### Step 9: 设置武器蓝图 WeaponSystemComponent 的 WeaponConfigID

DT_WeaponConfigs 的 Id 字段（ConfigID）需要写入武器蓝图的 WeaponSystemComponent 组件属性中。

⚠️ WeaponConfigID 是 WeaponSystemComponent 组件的属性，不是蓝图自身的变量。必须通过 `get_blueprint_components` 获取组件实例后设置。

```python
from unreal_engine.classes import Blueprint, DataTable
import unreal_engine as ue

root = ue.get_project_root()

# 获取 ConfigID（从 DT_WeaponConfigs）
dt = ue.load_object(DataTable, root + '/Asset/Data/Table/Weapon/DT_WeaponConfigs')
data = dt.data_table_as_dict()
config_id_lv1 = getattr(data['18'], 'Id_2_E925F48B4B1EE84561F1309EEE8B57EC', None)  # 10101
config_id_lv2 = getattr(data['19'], 'Id_2_E925F48B4B1EE84561F1309EEE8B57EC', None)  # 10102

# ===== 1级武器蓝图 =====
bp_w1 = ue.load_object(Blueprint, root + '/Asset/Blueprint/Prefabs/Weapons/BP_Weapon_{类型}_{名称}')
components = ue.get_blueprint_components(bp_w1)

for comp in components:
    if 'WeaponSystem' in str(comp.get_name()):
        comp.WeaponConfigID = config_id_lv1
        ue.log("Set " + comp.get_name() + " WeaponConfigID = " + str(config_id_lv1))

ue.compile_blueprint(bp_w1)
bp_w1.save_package()

# ===== 2级武器蓝图 =====
# 2级蓝图继承自1级，需要先添加 WeaponSystemComponent（继承的组件不可修改属性）
bp_w2 = ue.load_object(Blueprint, root + '/Asset/Blueprint/Prefabs/Weapons/BP_Weapon_{类型}_{名称}_Lv2')
comp_class = ue.find_class('BP_WeaponSystemComponent_C')
ue.add_component_to_blueprint(bp_w2, comp_class, 'WeaponSystemComponent')
ue.compile_blueprint(bp_w2)

# 再获取组件并设置 ConfigID
bp_w2 = ue.load_object(Blueprint, root + '/Asset/Blueprint/Prefabs/Weapons/BP_Weapon_{类型}_{名称}_Lv2')
components2 = ue.get_blueprint_components(bp_w2)

for comp in components2:
    if 'WeaponSystem' in str(comp.get_name()):
        comp.WeaponConfigID = config_id_lv2
        ue.log("Set " + comp.get_name() + " WeaponConfigID = " + str(config_id_lv2))

ue.compile_blueprint(bp_w2)
bp_w2.save_package()
```

## API 速查

| API | 用途 | 注意事项 |
|-----|------|---------|
| `objed_query_templates('Item', '枪械')` | 查询枪械模板列表 | 返回 JSON，模板名称在 `template_name` 字段 |
| `objed_query_templates('Item', '物品')` | 查询物品模板列表 | 弹药模板的 `category` 为 `子弹物品` |
| `objed_create_asset(type, asset_type, template, name)` | 从内置模板创建蓝图 | 路径自动确定，不能指定父类 |
| `create_blueprint(parent_cls, path)` | 以指定父类创建子蓝图 | ⚠️ 必须用此 API 创建2级蓝图 |
| `add_component_to_blueprint(bp, cls, name)` | 添加 SCS 组件 | 组件类名: `BP_WeaponSystemComponent_C` |
| `get_blueprint_components(bp)` | 获取蓝图 SCS 组件列表 | 用于设置组件属性如 WeaponConfigID |
| `compile_blueprint(bp)` | 编译蓝图 | 添加组件/变量后必须调用 |
| `objed_delete_asset(name, type)` | 删除物编资产 | 批量不超过3个 |

## 踩坑记录

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| ItemID 位数异常（9位而非7位） | 批量创建物品蓝图时编辑器无法确定顺序 | 逐个创建物品蓝图，每个创建后 `time.sleep(2)` 等待 ItemID |
| WeaponConfigID 设置无效 | 设置在蓝图自身变量上而非组件上 | 使用 `get_blueprint_components(bp)` 获取组件实例后设置 |
| 2级蓝图 WeaponConfigID 无法修改 | 继承的组件实例不可修改属性 | 先 `add_component_to_blueprint` 添加新组件实例，再设置 |
| Lv2 蓝图父类错误 | 使用 `objed_duplicate_asset` 复制 | 使用 `create_blueprint(parent_cls, path)` 以1级蓝图为父类创建 |
