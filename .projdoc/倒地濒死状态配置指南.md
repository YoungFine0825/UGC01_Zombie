# 倒地/濒死状态配置指南

## 问题背景

玩家血量归零后，应该进入倒地（濒死）状态等待队友救援，但实际直接进入了 `PawnState.Dead`（死亡）状态。

## 根因分析

C++引擎的死亡判断逻辑有两个关键条件：

### 条件1：NearDeathComponent.AnybodyCanHelp

**路径**：`UGCPlayerPawn` → `NearDeathComponent` → `AnybodyCanHelp`

- **未勾选**（默认）：C++引擎先调用 `HasAnyTeamatesCanHelp` 检查是否有**其他玩家**可以救援
  - 如果没有其他队友（单人模式）→ `HasAnyTeamatesCanHelp == False` → **直接死亡**
  - 如果有队友 → 继续检查 `bIsPlayerDirectlyDie`
- **勾选**：跳过 `HasAnyTeamatesCanHelp` 检查，即使没有队友也可以进入倒地状态

### 条件2：DA_GameModeGeneral.bIsPlayerDirectlyDie

**路径**：`DA_GameModeGeneral` → `bIsPlayerDirectlyDie`

- **False**（默认）：多人模式下，血量降至濒死阈值时进入倒地状态
- **True**：多人模式下，血量降至濒死阈值时直接死亡

## 执行优先级

```
1. 血量归零
2. 检查 NearDeathComponent.AnybodyCanHelp
   ├─ 未勾选 → 检查 HasAnyTeamatesCanHelp
   │   ├─ False（无队友）→ 直接死亡（无视 bIsPlayerDirectlyDie）
   │   └─ True（有队友）→ 继续下一步
   └─ 勾选 → 继续下一步
3. 检查 DA_GameModeGeneral.bIsPlayerDirectlyDie
   ├─ False → 进入倒地状态
   └─ True → 直接死亡
```

## 解决方案

### 单人模式下需要倒地状态

1. 打开 `UGCPlayerPawn` 蓝图
2. 找到 `NearDeathComponent`
3. 勾选 `AnybodyCanHelp = True`
4. 保存并编译

### 多人模式下需要倒地状态

1. 打开 `DA_GameModeGeneral`
2. 找到 `bIsPlayerDirectlyDie = False`（默认）
3. 保存

### 单人+多人都需要倒地状态

同时满足：
1. `UGCPlayerPawn.NearDeathComponent.AnybodyCanHelp = True`
2. `DA_GameModeGeneral.bIsPlayerDirectlyDie = False`

## 日志验证

### 成功进入倒地状态的日志

```
LogNearDeath: HasAnyTeamatesCanHelp myteamid=1 teammatesid=1 bCanHelpOthers=1
LogNearDeath: GotoLastBreathStatus HasAnyTeamatesCanHelp == True  ← 关键
角色进入了状态 PawnState.Dying
```

### 直接死亡的日志（问题）

```
LogNearDeath: HasAnyTeamatesCanHelp myteamid=1 teammatesid=1
LogNearDeath: GotoLastBreathStatus HasAnyTeamatesCanHelp == False  ← 关键
角色进入了状态 PawnState.Dead
```
