### 枪械蓝图创建规范 (AI Agent Rule)

本文档定义了创建枪械蓝图资产的完整流程，供 AI Agent 自动化执行。

> **枪械模板/弹药模板速查表** → [枪械蓝图参考表.md](枪械蓝图参考表.md)

---

## 资产命名规范

| 资产类型 | 命名格式 | 示例 |
|---------|---------|------|
| 1级枪械蓝图 | `BP_Weapon_{枪械类型}_{枪械名称}` | `BP_Weapon_SMG_Uzi` |
| 2级枪械蓝图 | `BP_Weapon_{枪械类型}_{枪械名称}_Lv2` | `BP_Weapon_SMG_Uzi_Lv2` |

⚠️ **虚幻引擎不支持文件名中包含 `-`（连字符）**。模板名称中的连字符在创建蓝图时必须替换为 `_`（下划线）。例如：`AC-VAL` → `BP_Weapon_Rifle_AC_VAL`，`SCAR-L` → `BP_Weapon_Rifle_SCAR_L`。
| 1级枪械物品蓝图 | `BP_Inventory_{枪械类型}_{枪械名称}` | `BP_Inventory_SMG_Uzi` |
| 2级枪械物品蓝图 | `BP_Inventory_{枪械类型}_{枪械名称}_Lv2` | `BP_Inventory_SMG_Uzi_Lv2` |
| 弹药物品蓝图 | `BP_Inventory_Bullet_{枪械名称}` | `BP_Inventory_Bullet_Uzi` |

枪械类型枚举：`Pistol`(手枪)、`SMG`(冲锋枪)、`Rifle`(突击步枪)、`Sniper`(狙击枪)、`ShotGun`(霰弹枪)、`MachineGun`(机枪)

## 创建流程 (严格按顺序执行)

### ⚠️ 前置条件：物品编辑器必须打开

**物品编辑器 UI 打开时，编辑器按递增规则分配正确的7位数 ItemID（如 8310050）；关闭时使用 Default 规则，分配错误的9位数 ID（如 831101001）。**

执行工作流前必须检查物品编辑器是否打开：

```python
# 检查物品编辑器是否打开
ctx = ue_read(queries=["ctx:"])
# 检查 opened_objed_tabs 是否包含 editor_type="Item"

# 如果未打开，尝试强制打开
ue.objed_open_editor('Item')

# 如果打开失败，停止工作并告知用户
```

**MCP 不可用时**：必须明确要求用户确认物品编辑器已打开，否则禁止执行物品蓝图创建步骤。

**执行过程中**：每次创建物品蓝图前，即时检测物品编辑器是否打开（MCP可用时），未打开则先尝试强制打开，失败则停止工作。

### ⚠️ 核心规则（必须遵守）

1. **物品编辑器必须打开**：创建物品蓝图前必须确保物品编辑器 UI 已打开，否则 ItemID 分配会出错
2. **逐把枪械执行**：每把枪械独立执行完整流程，**上一把枪械的全部流程（蓝图创建+物品蓝图+配置表）完成后才开始下一把**
3. **物品蓝图逐个创建**：每个物品蓝图创建后必须等待编辑器分配 ItemID，**确认 ItemID 为7位数且无误后再创建下一个物品蓝图**
4. **禁止批量创建物品蓝图**：不得同时创建多个物品蓝图，必须一个一个来
5. **枪械蓝图可快速创建**：Step 1-3（枪械蓝图）可以快速连续执行，不需要等待
6. **配置表随枪械完成**：每把枪械的物品蓝图创建完成后，立即配置 DT_WeaponConfigs 和 WeaponConfigID
7. **禁止私自修改 UGCBattleItem**：UGCBattleItem 的增删改由编辑器自动处理，AI Agent 不得手动操作该表

### 单把枪械完整流程

对每把枪械，按以下顺序执行，**全部完成后才进行下一把枪械**：

#### Step 1: 创建1级枪械蓝图

```python
path_w1 = ue.objed_create_asset('Item', '枪械', '{模板名称}', 'BP_Weapon_{类型}_{名称}')
```

#### Step 2: 给1级枪械蓝图添加 WeaponSystemComponent

```python
bp_w1 = ue.load_object(Blueprint, '{Step1返回的路径}')
comp_class = ue.find_class('BP_WeaponSystemComponent_C')
ue.add_component_to_blueprint(bp_w1, comp_class, 'WeaponSystemComponent')
ue.compile_blueprint(bp_w1)
bp_w1.save_package()
```

#### Step 3: 创建2级枪械蓝图

⚠️ 禁止使用 `objed_duplicate_asset`，必须用 `create_blueprint`。

```python
bp_w1 = ue.load_object(Blueprint, '{Step1返回的路径}')
bp_lv2 = ue.create_blueprint(bp_w1.GeneratedClass, root + '/Asset/Blueprint/Prefabs/Weapons/BP_Weapon_{类型}_{名称}_Lv2')
ue.compile_blueprint(bp_lv2)
bp_lv2.save_package()
```

#### Step 4: 创建1级物品蓝图 + 确认 ItemID + 设置 WeaponClass

⚠️ **创建前必须检查物品编辑器是否打开**，确认 ItemID 为7位数后再设置 WeaponClass。

```python
import time

# 检查物品编辑器是否打开（MCP可用时）
ctx = ue_read(queries=["ctx:"])
# 检查 opened_objed_tabs 是否包含 editor_type="Item"
# 如果未打开，尝试: ue.objed_open_editor('Item')
# 如果打开失败，停止工作

path_i1 = ue.objed_create_asset('Item', '物品', '{物品模板名称}', 'BP_Inventory_{类型}_{名称}')
bp_i1 = ue.load_object(Blueprint, path_i1)
bp_i1.save_package()  # 先保存

time.sleep(3)  # 等待编辑器分配 ItemID
bp_i1 = ue.load_object(Blueprint, path_i1)
item_id_lv1 = bp_i1.GeneratedClass.get_cdo().ItemID
assert len(str(item_id_lv1)) == 7, "ItemID 应为7位数，当前: " + str(item_id_lv1)

# 确认 ItemID 正确后才设置 WeaponClass
bp_w1 = ue.load_object(Blueprint, '{Step1返回的路径}')
bp_i1.GeneratedClass.get_cdo().WeaponClass = bp_w1.GeneratedClass
bp_i1.save_package()
```

#### Step 5: 创建2级物品蓝图 + 确认 ItemID + 设置 WeaponClass

⚠️ **创建前必须检查物品编辑器是否打开**。

```python
# 再次检查物品编辑器
ctx = ue_read(queries=["ctx:"])
# 确保物品编辑器仍打开

bp_i1 = ue.load_object(Blueprint, '{Step4返回的路径}')
bp_i_lv2 = ue.create_blueprint(bp_i1.GeneratedClass, root + '/Asset/Blueprint/Prefabs/Items/BP_Inventory_{类型}_{名称}_Lv2')
ue.compile_blueprint(bp_i_lv2)
bp_i_lv2.save_package()
bp_i_lv2 = ue.load_object(Blueprint, '{Step5创建的路径}')
bp_i_lv2.save_package()  # 先保存

time.sleep(3)
bp_i_lv2 = ue.load_object(Blueprint, '{Step5创建的路径}')
item_id_lv2 = bp_i_lv2.GeneratedClass.get_cdo().ItemID
assert len(str(item_id_lv2)) == 7, "ItemID 应为7位数，当前: " + str(item_id_lv2)

# 确认 ItemID 正确后才设置 WeaponClass
bp_w2 = ue.load_object(Blueprint, '{Step3创建的路径}')
bp_i_lv2.GeneratedClass.get_cdo().WeaponClass = bp_w2.GeneratedClass
bp_i_lv2.save_package()
```

#### Step 6: 创建弹药物品蓝图 + 确认 ItemID

⚠️ **创建前必须检查物品编辑器是否打开**。

```python
# 再次检查物品编辑器
ctx = ue_read(queries=["ctx:"])
# 确保物品编辑器仍打开

path_b = ue.objed_create_asset('Item', '物品', '{弹药模板名称}', 'BP_Inventory_Bullet_{名称}')
bp_b = ue.load_object(Blueprint, path_b)
bp_b.save_package()  # 先保存

time.sleep(3)
bp_b = ue.load_object(Blueprint, path_b)
item_id_bullet = bp_b.GeneratedClass.get_cdo().ItemID
assert len(str(item_id_bullet)) == 7, "ItemID 应为7位数，当前: " + str(item_id_bullet)
```

#### Step 8: 设置 WeaponConfigID

```python
# 1级
bp_w1 = ue.load_object(Blueprint, root + '/Asset/Blueprint/Prefabs/Weapons/BP_Weapon_{类型}_{名称}')
comps = ue.get_blueprint_components(bp_w1)
for c in comps:
    if 'WeaponSystem' in str(c.get_name()):
        c.WeaponConfigID = {ConfigID}
ue.compile_blueprint(bp_w1)
bp_w1.save_package()

# 2级
bp_w2 = ue.load_object(Blueprint, root + '/Asset/Blueprint/Prefabs/Weapons/BP_Weapon_{类型}_{名称}_Lv2')
comps2 = ue.get_blueprint_components(bp_w2)
if not comps2:
    ue.add_component_to_blueprint(bp_w2, ue.find_class('BP_WeaponSystemComponent_C'), 'WeaponSystemComponent')
    ue.compile_blueprint(bp_w2)
    bp_w2 = ue.load_object(Blueprint, root + '/Asset/Blueprint/Prefabs/Weapons/BP_Weapon_{类型}_{名称}_Lv2')
    comps2 = ue.get_blueprint_components(bp_w2)
for c in comps2:
    if 'WeaponSystem' in str(c.get_name()):
        c.WeaponConfigID = {ConfigID} + 1
ue.compile_blueprint(bp_w2)
bp_w2.save_package()
```

## API 速查

| API | 用途 | 注意事项 |
|-----|------|---------|
| `objed_query_templates('Item', '枪械')` | 查询枪械模板列表 | 返回 JSON |
| `objed_query_templates('Item', '物品')` | 查询物品模板列表 | 弹药模板 `category` 为 `子弹物品` |
| `objed_create_asset(type, asset_type, template, name)` | 从内置模板创建蓝图 | 路径自动确定 |
| `create_blueprint(parent_cls, path)` | 以指定父类创建子蓝图 | ⚠️ 必须用此 API 创建2级蓝图 |
| `add_component_to_blueprint(bp, cls, name)` | 添加 SCS 组件 | 组件类名: `BP_WeaponSystemComponent_C` |
| `get_blueprint_components(bp)` | 获取蓝图 SCS 组件列表 | 用于设置 WeaponConfigID |
| `compile_blueprint(bp)` | 编译蓝图 | 添加组件后必须调用 |
| `objed_delete_asset(name, type)` | 删除物编资产 | 批量不超过3个 |

## 踩坑记录

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| ItemID 位数异常（9位而非7位） | 批量创建物品蓝图时编辑器无法确定顺序 | 逐个创建物品蓝图，每个创建后 `time.sleep(3)` 等待 ItemID，确认7位数后再创建下一个 |
| Lv1 和 Lv2 ItemID 相同 | 创建间隔太短，编辑器复用了ID | 确保每个物品蓝图创建后等待3秒以上 |
| WeaponConfigID 设置无效 | 设置在蓝图自身变量上而非组件上 | 使用 `get_blueprint_components(bp)` 获取组件实例后设置 |
| 2级蓝图 WeaponConfigID 无法修改 | 继承的组件实例不可修改属性 | 先 `add_component_to_blueprint` 添加新组件实例，再设置 |
| Lv2 蓝图父类错误 | 使用 `objed_duplicate_asset` 复制 | 使用 `create_blueprint(parent_cls, path)` 以1级蓝图为父类创建 |
| UGCBattleItem ID 混乱 | 多把枪械同时创建物品蓝图 | 严格逐把枪械执行，每把完成全部流程后再进行下一把 |
